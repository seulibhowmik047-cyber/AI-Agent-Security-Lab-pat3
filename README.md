This project demonstrates practical AI security concepts including:

- AI System Security
- AI Agent Security
- Agent Lifecycle Management
- Identity and Permissions
- Least Privilege
- Data Security
- Shadow AI
- Data Overexposure
- Interaction Risk
- Data Loss Prevention (DLP)
- Data Security Posture Management (DSPM)
- AI Monitoring
- Threat Detection
- Security Alerts
- AI-assisted Incident Investigation
