# AI Agent Security

## Agent Security Questions

- What agents exist?
- Who created the agent?
- Who owns the agent?
- What can the agent access?
- What actions can the agent perform?
- Who can use the agent?
- What data can the agent access?

## Least Privilege

An AI agent should receive only the permissions required to perform its intended task.

## Example

Customer Support Agent:

Allowed:
- Customer records
- Orders
- Support tickets

Not Allowed:
- Payroll
- HR records
- Executive documents
- Financial records
