# AI Security Overview

## Three Core Layers

### 1. AI System
The AI application/model must be secured and monitored.

### 2. AI Agent
AI agents must have controlled permissions and defined responsibilities.

### 3. Data
Sensitive information accessed by AI must be protected.

## Core Questions

1. What AI systems exist?
2. What can AI access?
3. What can AI do?
4. Who owns the AI agent?
5. Is the AI system secure?
6. Is sensitive data exposed?

## Security Principle

AI Security = System + Agent + Data
