# AI Agent Lifecycle

## Lifecycle

1. Register
2. Scope
3. Monitor
4. Review
5. Retire

## Register

Record:

- Agent name
- Purpose
- Creator
- Owner
- Department
- Business purpose

## Scope

Define:

- Required permissions
- Data access
- Applications
- Allowed actions

## Monitor

Monitor:

- Agent activity
- Data access
- Users
- Interactions
- Suspicious behavior

## Review

Regularly verify:

- Is the agent still required?
- Is the owner valid?
- Are permissions still required?
- Is the agent behaving as expected?

## Retire

When no longer required:

- Disable agent
- Remove permissions
- Revoke credentials
- Delete/decommission agent
